# FitLife Flutter App

A beginner-friendly Flutter implementation of the provided FitLife reference.

## Run in Android Studio
1. Create/open a Flutter project named `fitlife_app`.
2. Replace `pubspec.yaml` and the `lib/` directory with the files in this package.
3. Add your own fitness photos to `assets/images/` using these exact names:
   - `splash.jpg` — outdoor mountain/lake fitness background
   - `workout.jpg` — full body workout photo
   - `hiit.jpg` — HIIT exercise photo
   - `yoga.jpg` — morning yoga photo
4. Run `flutter pub get`.
5. Run `lib/main.dart` on an Android emulator or connected device.

If you do not add images yet, the app uses colored placeholders so it can still launch.

## Included screens
- Splash / Get Started
- Home dashboard
- Workout details
- Workout cards and bottom navigation styling

This is a UI prototype. Login, nutrition, profile, progress tracking, and workout timing are not connected to a backend.
